# Tutorial

The tutorial notebook used to live here as well as under `docs/`, and
the two copies had drifted apart. There is now one of it, next to the
rest of the documentation:

- **Read it online**: <https://gtrace.readthedocs.io/en/latest/tutorial.html>
- **Run it yourself**: [`docs/source/tutorial/gtrace-tutorial.ipynb`](../../docs/source/tutorial/gtrace-tutorial.ipynb)

It covers the coordinate and direction conventions, Gaussian beams,
mirrors, sequential and non-sequential tracing, the KAGRA input mode
cleaner as a worked example, and the `OpticalLayout` container together
with the interactive viewer.

What remains in this directory is the material the notebook does not
replace:

| | |
|---|---|
| `Tutorial.pptx` | the slides the tutorial was first presented as |
| `OMC-Mod-Layout-OBS3-R500.dwb` | a worked layout used with the slides |

The figures and the DXF output that used to sit beside them went with
the notebook: they were copies of files the notebook produces, and it
now produces them next to itself under `docs/source/tutorial/`.

See [`../Slides/`](../Slides) for the background material on ABCD
matrices, the q-parameter and the basic concepts.
