Tutorial
===============================

You can find a basic tutorial of gtrace in its `GitHub repository <https://github.com/asoy01/gtrace>`_.

You can download the gtrace source tree by::

    git clone https://github.com/asoy01/gtrace.git

Or the direct link to the tutorial file is here: https://github.com/asoy01/gtrace/blob/master/Manuals/Tutorial/gtrace-tutorial.ipynb

Or you can find it directly here:

.. toctree::
   :maxdepth: 1

   tutorial/gtrace-tutorial

---------------

The tutorial uses the low level interface throughout: it builds mirrors and beams and passes them around itself. For the container that collects them into one object, and for the interactive viewer, see :doc:`layout` and :doc:`viewer`. A runnable demonstration of both lives in the source tree at ``tests/OpticalLayout_demo.ipynb``.
